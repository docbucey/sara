# SARA Gaming: Input Training as RPG/Action Games

## Overview
All SARA games are designed as full input training systems, disguised as a series of RPG and action games. These games adapt to user devices and skills, providing calibration and training while delivering engaging gameplay.

## Folder Structure
- RPG/      : Role-playing game modules for input training
- Action/   : Action game modules for reflex and accuracy training
- Calibration/: Core calibration games (reaction, aiming, navigation)

## Graphics & UI
- All graphics and UI textures are developed in Blender and stored in the Graphics/Textures/ folder.
- The UI/ folder contains reusable UI components and layouts for all games.
- During initial builds, games will use onboard/default graphics and UI, with Blender assets integrated as they are completed.

## Integration
- Games are discoverable and callable by SARA’s SDK/MAMA pillars.
- Input mapping and device adaptation are core to every game module.
- As graphics and UI assets are finished, they will be swapped in seamlessly.

Continue developing graphics and UI in Blender. Use the RPG/ and Action/ folders for new game modules, and Graphics/Textures/ for all visual assets.
