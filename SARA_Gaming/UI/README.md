# SARA Gaming UI

## Purpose
This folder contains all reusable UI components, layouts, and templates for SARA’s gaming and calibration modules.

## Workflow
- Default UI and textures are used during initial builds.
- As you finish graphics and UI textures in Blender, add them to Graphics/Textures/ and update UI components here.
- UI modules are designed for accessibility, device adaptation, and seamless integration with SARA’s SDK/MAMA pillars.

## Structure
- Place XAML, resource dictionaries, and C# UI classes here.
- Reference Blender-generated textures from Graphics/Textures/.
- Update UI components as new assets are completed.
