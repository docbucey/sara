# Voice Input UI Scaffold

This folder contains scaffolding for SARA's voice input training and integration modules.

## Purpose
- Provide reusable components for voice input in both gaming and productivity (CAD/video) workflows.
- Support accessibility and adaptive input for all users.

## Structure
- Place C# classes, XAML, or config files for voice input UI here.
- Use generic UI templates as a starting point; refine as you gather real usage data.
- Integrate with SARA's ADA and Night Shift Mode as needed.
