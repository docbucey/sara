# Generic UI Scaffold

This folder contains generic UI templates and components for SARA's Night Shift Mode, gaming, and productivity workflows.

## Purpose
- Provide a flexible, accessible starting point for all on-screen UI.
- Enable rapid prototyping and iterative refinement.

## Structure
- Place XAML, resource dictionaries, and C# UI classes here.
- Use these templates for both games and 3D CAD/video production until custom UI is needed.
- Update as you develop specialized UI for specific workflows.
