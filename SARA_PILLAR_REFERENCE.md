# SARA Pillar Reference

This file is for Copilot/AI agent use only. It documents the five canonical pillars of SARA Gen1, their purpose, and will be expanded with protocol and interface details as the spec sheet is refined. Do not confuse this file with any implementation code or protocol files in the actual pillar directories.

---

## Pillar 1: sara_coregen1
- **Purpose:** Identity, lifecycle, and machine-profile engine
- **Responsibilities:**
  - Load system identity
  - Validate machine profile
  - Initialize subsystems
  - Maintain deterministic state

## Pillar 2: sara_controlgen1
- **Purpose:** Orchestration and command-routing
- **Responsibilities:**
  - Session management
  - Control wall routing
  - Subsystem coordination
  - Action authorization

## Pillar 3: sara_securitygen1
- **Purpose:** Security and boundary enforcement
- **Responsibilities:**
  - Data access rules
  - Capability gating
  - Safe execution boundaries
  - ADA-aligned safety constraints

## Pillar 4: sara_mamagen1
- **Purpose:** ADA-compliant human interface
- **Responsibilities:**
  - Multimodal accessibility
  - Adaptive input/output
  - Voice, text, and assistive pathways
  - Ergonomic interaction logic

## Pillar 5: sara_sdkgen1
- **Purpose:** Extension and plugin development
- **Responsibilities:**
  - Subsystem discovery
  - Plugin registration
  - Developer-facing APIs
  - Long-term extensibility
