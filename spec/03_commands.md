# 03 Commands — Smithy Core Extension

This document lists all commands provided by the Smithy core VS Code extension.

---

## Command List

### smithy.start
- Starts the Smithy backend and initializes device input routing.

### smithy.stop
- Stops the Smithy backend and disconnects all device input.

### smithy.reload
- Reloads the Smithy extension and configuration.

### smithy.sendToBlender
- Sends the current command or payload to Blender.

### smithy.sendToSara
- Sends the current command or payload to SARA.

### smithy.bindDeviceInput
- Maps a device input (G13, HOTAS, mouse, voice) to a Smithy command or macro.

### smithy.runMacro
- Executes a predefined macro (sequence of commands or actions).

### smithy.loadProfile
- Loads a device/profile configuration for Smithy.

### smithy.saveProfile
- Saves the current device/profile configuration.

### smithy.openLog
- Opens the Smithy log file or output channel.

### smithy.openSessionFolder
- Opens the current Smithy session folder in VS Code.

---

## Notes
- All commands are accessible from the VS Code command palette.
- Device input and macro commands are designed for gaming and creative workflows.
- Profiles allow quick switching between device setups and command bindings.
