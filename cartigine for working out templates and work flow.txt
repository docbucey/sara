# CARTIGENE DATA DUALITY PRINCIPLE (ONE-PAGE SPEC)

Status: Draft for experimental validation
Date: 2026-03-11
Author intent: Define a testable principle for data behavior outside software-only interpretation.

## 1) Principle Statement

Data is modeled as dual-nature:
- Continuous mode (wave-like): phase, lag, resonance, coherence.
- Discrete mode (particle-like): symbols, bits, chunk boundaries, grain structure.

System failures increase when analysis uses only discrete structure while transport and timing effects are continuous.

## 2) Core Variables

- x(t): transmitted signal or source representation.
- y(t): received/reconstructed signal.
- f: drive frequency.
- tau: lag shift between source and received.
- w: grain window size (bytes/symbols/samples).
- H_w: entropy in window w.

## 3) Test Metrics

1) Lag-optimal shift:

tau* = argmax_tau corr(x(t), y(t + tau))

2) Resonance gain:

R(f) = |Y(f)| / |X(f)|

3) Grain instability:

G = Var(H_w)

4) Composite integrity score:

I = C * (1 - D) * (1 - G_norm)

Where:
- C is normalized coherence in [0, 1]
- D is normalized lag drift in [0, 1]
- G_norm is normalized grain-instability in [0, 1]

## 4) Hypothesis

There exists a system-specific resonance band f* where:
- lag drift is minimized,
- coherence is maximized,
- grain instability is reduced,
- and recovered payload integrity improves.

Important: concert B-flat can be a discovered local optimum, not a universal constant.

## 5) Heaviside-Style Pass Criteria

Define gate function:

H(z) = 1 if z >= 0 else 0

Pass gates:
- P1 = H(C - C_min)
- P2 = H(D_max - D)
- P3 = H(G_max - G_norm)
- P4 = H(I - I_min)

Overall pass:

PASS = H((P1 + P2 + P3 + P4) - T)

Recommended start:
- C_min = 0.90
- D_max = 0.10
- G_max = 0.20
- I_min = 0.85
- T = 4 (all gates required)

## 6) Physical Experiment Protocol (Outside Code)

1. Generate repeatable payloads (text, structured binary, mixed entropy).
2. Transmit through physical medium at swept carrier/symbol rates.
3. Measure lag, coherence proxy, and payload reconstruction quality.
4. Compute grain windows and entropy variance.
5. Apply Heaviside gates.
6. Compare resonance candidates and pick f* by highest stable pass count.

## 7) Claims This Spec Can Support

- "Data has measurable dual behavior under transport constraints."
- "Representation mismatch (discrete-only model on continuous channel) predicts failures."
- "A reproducible resonance band can improve integrity for a given stack."
