SECTION 1 — PUPPY (ROOT PRIMITIVE)
----------------------------------
Puppy is the universal SLAM primitive. All SLAM entities begin
as a Puppy unless explicitly defined otherwise (Trainer).

Puppy Forms:
1. Primitive Puppy:
   <name> puppy%(payload)%

2. Connector Puppy:
   %(from)% <puppy_name> %(to)%

3. Control-Flow Puppy:
   <name> puppy%(state)% for %(condition)%

Puppy Responsibilities:
- Holds Sequians
- Acts as hardware-side primitive

MDBP (Machine Data Base Primitive):
- Hardware metadata container
- Stored as Puppy payload
- Used by HAL, MAMA, and Tagger
- Contains vendor, model, version, flags, capabilities

------------------------------------------------------------

SECTION 2 — GALVANTIS REPLACEMENT RULE
--------------------------------------
SLAM does not use traditional primitives.

Removed:
- tuple, dict
- boolean
Replaced With:
- Sequian (universal value holder)


SECTION 3 — SEQUIAN (VALUE SYSTEM)
----------------------------------
Sequian is the universal SLAM value container.

Numeric Sequians:
- All numbers auto-normalize to scientific notation
- Internal form:
    mantissa: normalized absolute value
    exponent: magnitude-derived
    sign: +1 or -1

Examples:
Input: -1
Stored: mantissa=1 exponent=0 sign=-1

Input: -3.45678^3456
Stored: mantissa=3.45678 exponent=3456 sign=-1

Input: 0.00000042
Stored: mantissa=4.2 exponent=-10 sign=1

Boolean/Control States:
0  = false
1  = true
2  = else-if
3  = else
10 = loop count
-1 = until flip
99 = max/all

- dict-like: seq:{key:value}


SECTION 4 — NEXUS (ARRAY REPLACEMENT)
Nexus replaces arrays, lists, vectors.
Nexus Properties:
- Multi-state container
- Compatible with CartiGene
- Compatible with NexusSphere
- Flow-safe
- Hardware-safe
- Substrate-native

Nexus Example:
<n> puppy%(nexus:[state1, state2, state3])%

------------------------------------------------------------

SECTION 5 — CARTIGENE (STATE ENGINE)

Math Primitives:
laggy = runtime / expected_runtime
shi = (memory + footprint) / (runtime + 1)
rot = (Δ1 * Δ2) < 0

Purpose:
- Stability evaluation
- Oscillation detection
- Rotation detection
- Resonance scoring
- Noise stabilization

continuity_tests:

- CartiGene stabilizes noisy hardware signals.
- NexusSphere ensures continuity across hardware events.

Hardware Flow:

    %(sensor:temp)% <filter> %(thermal_bus)%

This makes building engines (graphics, audio, physics, robotics)
as simple as connecting Puppies.

SECTION 8 — PARENTHETIC PAYLOAD RULE
--------------------------------------------------------------------

------------------------------------
All SLAM payload blocks using the %()% form must contain
comma-separated entries. This applies to all SLAM types,
including Puppy, Sequian, Nexus, CartiGene, NexusSphere,
MDBP, and hardware mapping structures.

Rule:
    %(<entry_1>, <entry_2>, <entry_3>, ... )%

Notes:
- No whitespace rules enforced; spaces are optional.
- Trailing commas are not allowed.
- Single-entry payloads do not require a comma.
- Nested %()% blocks must also follow comma separation.
- This rule ensures deterministic parsing for SLAM_MAMA,
  the File Engine, and the HAL registry.

Examples:

Valid:
    puppy%(1,2,3)%
    puppy%(mantissa:3.14, exponent:0, sign:1)%
    puppy%(nexus:[1,2,3], type:vector)%
    %(audio_in, gain_stage)% <router> %(speaker_out)%

Invalid:
    puppy%(1 2 3)%          # missing commas
    puppy%(mantissa:3.14 exponent:0)%  # missing comma
    puppy%(a,,b)%           # double comma not allowed

SECTION 9 — STUB PRIMITIVE (UNRESOLVED CODE PLACEHOLDER)
------------------------------------------------------------

#= STUB PRIMITIVE DEFINITION =#
# Stubs are substrate-level placeholders for incomplete logic.
# They allow coders and AI systems to safely mark unfinished
# sections without breaking SLAM_MAMA, HAL, or lowering.
#
# Stubs are treated as "incomplete" and MUST error if reached
# during lowering or execution. They are always resolved first
# by AI-assisted coding tools.
#
# Syntax:
#     <name> stub%(reason, expected_behavior)%
#
# Rules:
# - Payload inside %()% must follow comma-separated rule.
# - Stubs cannot be empty.
# - Stubs cannot be used in connector syntax.
# - Stubs cannot be used in control-flow syntax.
# - Stubs must be resolved before the SLAM file is valid.
#
# Behavior:
# - If lowering encounters a stub → HARD ERROR.
# - If execution encounters a stub → HARD ERROR.
# - If AI-assisted coding scans a file → stubs are FIRST priority.
#
# Examples:
#     <gpu_stage_3> stub%(TODO: rasterizer_math, missing:core_logic)%
#     <driver_init> stub%(pending_docs, expected:init_sequence)%
#
# This is the "special case" of Machine Funkiness:
# - Specs = defined behavior
# - Parentheticals = work-in-progress
# - Stubs = incomplete, must error
#
# Stubs prevent silent failures and protect the substrate.
#= END STUB PRIMITIVE DEFINITION =#

# They sit above the substrate and act on SLAM structures.
#

infer():
    # Generate new state from existing states.
    # Uses NexusSphere rotation + CartiGene resonance.
    # Produces a Sequian or Nexus output.

    # Retrieve stored deflections, memory events, or historical states.
    # Uses NexusSphere.deflection_trajectories.

deflect():
    # Apply a directional shift to a state.
    # Used for context updates, memory shaping, and reasoning pivots.

rotate():
    # Perform geometric rotation of reasoning state.
    # Uses NexusSphere.rotation_logic (intake, compression, integration).

stabilize():
    # Apply CartiGene’s BuceyShift and oscillation dampening.
    # Produces a stable Sequian or Nexus.

resonate():
    # Evaluate resonance quality between states.
    # Uses CartiGene.shi and rotation/oscillation detection.

compress():
    # Reduce state complexity while preserving meaning.
    # Uses NexusSphere.compression and CartiGene.grain.

integrate():
    # Merge new data with historical deflections.
    # Uses NexusSphere.integration and CartiGene.stability metrics.

filter():
    # Remove noise, hallucinations, or unstable states.
    # Uses CartiGene.noise metrics + NexusSphere.hallucination_filter.

    # Validate reasoning continuity across time.

------------------------------------

- Stability evaluation

SXF PREAMBLE — BINARY EXECUTION FORMAT
------------------------------------------------------------
#= SXF_PREAMBLE =#
# SXF (Sara Executable File) is the binary representation of
# the SLAM substrate. All SLAM constructs (Puppy, Sequian,
# Nexus, CartiGene, NexusSphere, MDBP, connectors, stubs,
# specs, and parentheticals) are lowered into SXF blocks.
#
# SXF is the binary axis. When Flood-Search selects SXF as
# the output target, the system must use the SXF mapping
# tables exclusively.
#
# Rule:
#   "These are the binaries."
#
# Meaning:
# - SXF is the final executable form of SLAM.
# - SXF is hardware-agnostic and substrate-native.
# - SXF is deterministic and self-describing.
# - SXF is the ground truth for all other mappings.
# - SXF is the lowest-level representation of SLAM.
#
# This preamble must appear before any SXF header, block
# layout, numeric encoding, or routing table definitions.
#= END SXF_PREAMBLE =#

------------------------------------------------------------
SXF_HEADER (BINARY BLOCK 0x01)
------------------------------------------------------------
#= SXF_HEADER_BLOCK =#
Block ID:
    0x01

Binary Layout (in order):
    [0x00] MAGIC          (4 bytes)   = "SXF0"
    [0x04] VERSION_MAJOR  (1 byte)
    [0x05] VERSION_MINOR  (1 byte)
    [0x06] EVOLUTION      (1 byte)
    [0x07] GENERATION     (1 byte)
    [0x08] FLAGS          (2 bytes)
    [0x0A] KENNEL_TYPE    (1 byte)
    [0x0B] LANGUAGE_ID    (1 byte)
    [0x0C] TIMESTAMP      (8 bytes)
    [0x14] LOCATION_HASH  (4 bytes)
    [0x18] MDBP_POINTER   (8 bytes)
    [0x20] RESERVED       (16 bytes)

Total Size:
    48 bytes (0x30)

Behavior:
- Loader validates identity and jumps to hardware metadata.
#= END SXF_HEADER_BLOCK =#

------------------------------------------------------------
SXF_BLOCK_INDEX (BINARY BLOCK 0x02)
------------------------------------------------------------
#= SXF_BLOCK_INDEX =#
Block ID:
    0x02

Binary Layout:
    [0x00] BLOCK_ID      (1 byte)
    [0x01] NUM_BLOCKS    (1 byte)
    [0x02] BLOCK_ENTRIES (n * 12 bytes):
        [0x00] BLOCK_TYPE (1 byte)
        [0x01] RESERVED   (1 byte)
        [0x02] OFFSET     (8 bytes)
        [0x0A] SIZE       (2 bytes)

Behavior:
- Provides fast lookup for all SXF blocks.
#= END SXF_BLOCK_INDEX =#

------------------------------------------------------------
SXF_NUMERIC (SEQUIAN → BINARY, BLOCK 0x03)
------------------------------------------------------------
#= SXF_NUMERIC_BLOCK =#
Block ID:
    0x03

Binary Layout (per entry):
    [0x00] MANTISSA   (8 bytes, float64)
    [0x08] EXPONENT   (2 bytes, int16)
    [0x0A] SIGN       (1 byte)
    [0x0B] FLAGS      (1 byte)

Behavior:
- Stores normalized Sequian numeric values.
#= END SXF_NUMERIC_BLOCK =#

------------------------------------------------------------
SXF_NEXUS_BLOCK (BINARY BLOCK 0x04)
------------------------------------------------------------
#= SXF_NEXUS_BLOCK =#
Block ID:
    0x04

Binary Layout:
    [0x00] NUM_STATES      (2 bytes)
    [0x02] STATE_OFFSETS   (NUM_STATES * 4 bytes)
    [0x??] STATE_DATA      (variable)

Behavior:
- Supports nested Nexus structures.
#= END SXF_NEXUS_BLOCK =#

------------------------------------------------------------
SXF_STATE_TABLE (CARTIGENE, BLOCK 0x05)
------------------------------------------------------------
#= SXF_STATE_TABLE =#
Block ID:
    0x05

Binary Layout (per entry):
    [0x00] STATE_ID     (2 bytes)
    [0x02] GRAIN        (8 bytes)
    [0x0A] LAGGY        (8 bytes)
    [0x12] SHI          (8 bytes)
    [0x1A] OSC          (8 bytes)
    [0x22] ROT          (8 bytes)
    [0x2A] BUCEYSHIFT   (8 bytes)
    [0x32] FLAGS        (2 bytes)

Behavior:
- Stores CartiGene stability metrics.
#= END SXF_STATE_TABLE =#

SXF_GEOMETRY (NEXUSSPHERE, BLOCK 0x06)
------------------------------------------------------------
#= SXF_GEOMETRY_BLOCK =#
